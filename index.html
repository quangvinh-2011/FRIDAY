Cài đặt FRIDAY

FRIDAY gọi API AI trực tiếp từ trình duyệt (chuẩn OpenAI Chat Completions). API key chỉ lưu trong localStorage trên máy này, không bị lộ ra ngoài.

Gợi ý các API tương thích miễn phí / có phí
  • Pollinations — https://gen.pollinations.ai/v1 (key tại enter.pollinations.ai)
  • OpenRouter — https://openrouter.ai/api/v1 (có model free tier)
  • Groq — https://api.groq.com/openai/v1 (phản hồi rất nhanh)
  • OpenAI — https://api.openai.com/v1
